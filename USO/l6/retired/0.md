# USO/l6/retired/

**Object:** Directory for retired or superseded internal states and bindings that are no longer current.
**Path:** `USO/l6/retired/` · **Layer:** L6 — LIBRARY · **Owner:** USO/l6/

## What this directory is

"Directory for retired or superseded internal states and bindings that are no longer current." A state placed here is preserved, not deleted. It stays readable at a path that names it as retired, so that the retirement itself is reconstructable.

In practice, a state filed here is recorded, preserved, compared, branched, superseded, retired, or reconstructed ("record, preserve, compare, branch, supersede, retire, reconstruct"); it is accepted when "Retirement preserves the record rather than erasing it" and when "Correction does not require deletion of prior state." Nothing here is a current gate, contract, or sheet of any layer.

## Why it exists

"Implements retirement as preservation rather than deletion, including the history of peer bindings that are no longer active."

Deletion would make the prior state recoverable only from Git, which records repository change events and not scientific memory.

## Holds

- Retired or superseded internal states: prior gate files, prior sheets, prior drafts, prior scaffolds.
- Retired bindings: the history of peer bindings that are no longer active.
- In this repository:
  - `USO/l6/retired/scaffold-2026-08-20/` — the pre-harmonization scaffold, preserved verbatim at its original relative paths, with the owner's retired README working sketch. See `USO/l6/retired/scaffold-2026-08-20/0.md`.
  - `USO/l6/retired/specification-draft-2026-09-03/` — the superseded draft of the architecture specification (PDF and text conversion). See `USO/l6/retired/specification-draft-2026-09-03/0.md`.
  - `USO/l6/retired/specification-2026-09-04/` — the specification as it stood on 4 September 2026: the owner's authored document, its canonical Markdown, and the generated rendering, superseded by the version of 6 September 2026. See `USO/l6/retired/specification-2026-09-04/0.md`.

## Does not hold

- Branch history, corrections, failures, unresolved paths, and reconstructable development over time — `USO/l6/history/` (the spec's history/ Prose cell).
- Active peer bindings — `L7/peering/`.
- External provenance of a retired state's sources — `L7/provenance/`.
- The current specification — `USO/l4/work/writing/7lm-harmonized-architecture-specification.docx` and `.md`. The superseded draft and the retired prior version here do not control anything.
- Any current layer sheet. A `0.md` beneath this directory that is not at the root of a retired set is a retained prior state, not a gate.

## Boundary / traversal rule

For an externally encountered object, L7 is the boundary and owns its external provenance/governance relation. L6 is the first interior layer used to reconstruct prior internal states, changes, failures, supersession, and retirement before deeper inspection.
