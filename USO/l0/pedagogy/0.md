## What this directory is

Directory for system-level traversal and attachment pedagogy. The L0 sheet owns "System-level traversal/attachment pedagogy as a directory/function, without making Pedagogy a fifth rail." This directory is that function: the place where the bounded object explains how it is traversed (construction outward from L0, inspection inward from L7) and how it attaches to other objects (the contextual semantic route through L7 egress and ingress, and the peer-1/object-1 form of that attachment), stated as teaching, not as a rule that changes what any layer owns.

In practice a person filing here writes the explanation a reader needs to walk this object's layers and its peering relations correctly. Pedagogy here is a directory and a function; it is not a rail, and it supplies no rail's local meaning. The spec's direction rule bounds what pedagogy may do: "Description does not become prescription merely because the structure can be traversed."

## Why it exists

Keeps pedagogy explicit without turning it into a fifth philosophical rail. The four rails carry distinctions; this directory carries the explanation of how the whole is used, so that explanation is never mistaken for a fifth source of foundational meaning.

## Holds

- System-level traversal pedagogy: how construction proceeds L0→L1→L2→L3→L4→L5→L6→L7 and how authorized external inspection proceeds L7→L6→L5→L4→L3→L2→L1→L0.
- Attachment pedagogy: how this object depends on another "without owning, copying, redefining, or maintaining both objects' foundational semantics," and the route "Source L0 definition → source L7 egress → receiving L7 ingress → receiving L0."
- The exemplar reading the spec retains for teaching: "AUTONOMOUS and AUDITONOMOUS are retained as pedagogical exemplars: EXEMPLAR AUTO and EXEMPLAR AUDIT," whose repositories "are implementation work in progress; their current layouts do not control the architecture."

## Boundary / traversal rule

L0/semantics contains the semantic representation authored by the bounded thing. An externally owned definition is not copied into L0 merely to populate the directory. Pedagogy explains traversal and attachment; it does not perform a binding, declare a state, or settle a reserved term.
