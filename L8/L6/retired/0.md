# L8/L6/retired/

**Object:** Directory for retired or superseded internal states or relations that are no longer current.
**Path:** `L8/L6/retired/` · **Layer:** L6 — LIBRARY · **Owner:** L8/L6/

## What this directory is

This directory represents internal states or relations that are no longer current but remain relevant to reconstruction of the bounded object's history. Retirement distinguishes a prior state from the current state without treating the prior state as though it never existed.

The architectural property is reconstructability. 7LM does not require one physical retention mechanism or a universal no-deletion rule. A repository may satisfy reconstructability through retained files, version-control history, explicit retirement records, archival storage, or another adequate mechanism.

**Repository implementation note.** This repository currently uses retained retired trees together with Git and L6 history records. That is an implementation of the L6 function, not the definition of retirement for every 7LM use.

## Why it exists

Keeps superseded internal states separately identifiable so reconstruction does not confuse them with the current object. The mechanism may include physical retention, explicit archival reference, version control, or another reconstructable representation.

## Holds

- Retired or superseded internal states: prior gate files, prior sheets, prior drafts, prior scaffolds.
- Prior states of external relationships, including peering relations, when those states are part of the bounded object's reconstructable internal history.
- In this repository:
  - `L8/L6/retired/scaffold-2026-08-20/` — the pre-harmonization scaffold, preserved verbatim at its original relative paths, with the owner's retired README working sketch. See `L8/L6/retired/scaffold-2026-08-20/0.md`.
  - `L8/L6/retired/specification-draft-2026-09-03/` — the superseded draft of the architecture specification (PDF and text conversion). See `L8/L6/retired/specification-draft-2026-09-03/0.md`.
  - `L8/L6/retired/specification-2026-09-04/` — the specification as it stood on 4 September 2026: the owner's authored document, its canonical Markdown, and the generated rendering, superseded by the current version. See `L8/L6/retired/specification-2026-09-04/0.md`.

## Does not hold

- Branch history, corrections, failures, unresolved paths, and reconstructable development over time — `L8/L6/history/` (the spec's history/ Prose cell).
- Current peering relationships — `L7/peering/`.
- External provenance of a retired state's sources — `L7/provenance/`.
- The current specification — `L8/L4/work/writing/7lm-harmonized-architecture-specification.docx` and `.md`. The superseded draft and the retired prior version here do not control anything.
- Any current layer sheet. A `0.md` beneath this directory that is not at the root of a retired set is a retained prior state, not a gate.

## Boundary / traversal rule

For an externally encountered object, L7 is the boundary and owns its external provenance/governance relation. L6 is the first interior layer used to reconstruct prior internal states, changes, failures, supersession, and retirement before deeper inspection.
