# L8/L6/

**Object:** Library: retained reference material and reconstructable internal memory.
**Path:** `L8/L6/` · **Layer:** L6 — LIBRARY · **Owner:** L8/L6/ — the owner of retained internal reference material and the reconstructable memory of how the bounded object developed.

L6 is the Library of the bounded scientific object. It holds durable internal reference material needed to orient or continue the work, together with the reconstructable memory of prior states, failures, corrections, supersession, retirement, and development. It does not decide the L5 research judgment and does not re-own external provenance. Current reference material can therefore live at L6 without becoming "history" merely because the Library also preserves history.

### Owns / represents
- durable internal reference material used to orient or continue the bounded object's work
- prior internal states and versions
- branch history and decision history
- failed paths and unresolved obligations
- corrections, supersession, retirement, and reconstructable memory

### What occurs here
- retain, reference, record, compare, branch, supersede, retire, and reconstruct
- preserve enough distinction among current reference material, prior states, and later corrections to reconstruct their relation
- orient inspection or continuation of the work

### Boundary indicators
- Prior internal states and changes are reconstructable.
- Current reference material can be distinguished from prior or retired states.
- External source/provenance references resolve back to L7 rather than becoming L6-owned provenance.
- A correction or retirement leaves enough retained information to reconstruct the earlier state and its relation to the later one.

## Git and scientific memory

Git history can support L6 reconstruction, but Git history and the L6 Library are not the same object. Git records repository change events; L6 represents the retained reference context and scientific/internal relations needed to orient and reconstruct the work. External source, authority, and prior-art provenance remain L7-owned.

Commit identifiers may serve as orientation pointers to repository change events. They can support reconstruction, but they do not by themselves replace the L6 representation of the reference context and internal relations that matter scientifically.
