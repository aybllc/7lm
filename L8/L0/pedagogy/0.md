## What this directory is

Directory for system-level traversal and attachment pedagogy. The L0 sheet owns system-level traversal/attachment pedagogy as a directory/function without making Pedagogy a fifth rail. This directory explains how the bounded object is traversed and how different kinds of external relation can be read. Peering is taught as one relationship pattern at L7, not as the universal route by which external material enters research.

Pedagogy here explains how a reader can walk the layers, distinguish representations, and recognize boundary relations. It is a directory and a function, not a fifth rail, and it supplies no rail's local meaning. Description does not become prescription merely because the structure can be traversed.

## Why it exists

Keeps pedagogy explicit without turning it into a fifth philosophical rail. The four rails carry distinctions; this directory carries the explanation of how the whole is used, so that explanation is never mistaken for a fifth source of foundational meaning.

## Boundary / traversal rule

L0/semantics contains the semantic representation used by the bounded thing. Source origin is represented through provenance where relevant; peering applies only when a counterpart relationship is represented. Pedagogy explains traversal and relation without creating the represented relation itself.
