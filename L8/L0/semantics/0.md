# L8/L0/semantics/

**Object:** Directory for the Semantic rail content authored by this bounded object.
**Path:** `L8/L0/semantics/` · **Layer:** L0 — LAYER 0 · **Owner:** L8/L0/

## What this directory is

Directory for the Semantic rail content authored by this bounded object. The Semantic rail is one of the four rails the L0 sheet names, and it is the rail the spec's boundary rule names directly: "L0/semantics contains the semantic representation authored by the bounded thing." The spec's note fixes the reading: "Current correction: L0/semantics is the semantic version we make of the thing. If we do not make one, the directory is not populated with someone else’s definition."

In practice a person filing here records the semantic representation this object actually authored — its own vocabulary, its own reading of what its terms mean — binds it to this rail, states ambiguity as ambiguity, and versions a changed distinction rather than rewriting prior use. Definitions actually authored by this object go one level down, in `L8/L0/semantics/definitions/`. An externally owned definition that this object uses is referenced with its immutable external-ownership tag; it is not rewritten here, and it is not "counted as local authorship."

## Why it exists

Keeps local semantic meaning separate from externally owned definitions and later formal representation. The two things this directory is kept apart from have their own owners: external definitions at `L7/`, and the formal representation of the same meaning at `L8/L2/`.

## Holds

- Semantic-rail representation locally authored by this bounded object.
- The child directory `definitions/` for definitions actually authored by this object.
- Statements of ambiguity or unresolved meaning, recorded as unresolved.
- Versioned prior semantic distinctions where a distinction has changed.
- References to externally owned semantic inputs, each carried as an exact named external semantic binding with object identity, owner, source layer, version, ingress binding, and immutable status — the reference, not the copied definition.

## Does not hold

- Externally owned definitions copied inward — bound through `L7/peering/` (ingress) and represented at `L7/provenance/`.
- Prior art — `L7/provenance/prior-art/`.
- Ontological, epistemic, or universality distinctions — `L8/L0/ontology/`, `L8/L0/epistemic/`, `L8/L0/universality/`.
- Admissible states — `L8/L1/state-space/`.
- Exact formulas, relations, operators, or proofs — `L8/L2/formal-mathematics/`.
- Applied, tolerant, adaptive, or engineering formulas — `L8/L3/engineering-mathematics/`.
- Research claims and thesis statements — `L8/L5/research/lanes/`.

## Boundary / traversal rule

L0/semantics contains the semantic representation authored by the bounded thing. An externally owned definition is not copied into L0 merely to populate the directory. The L0 acceptance check applies here in full: "No peer definition is locally redefined merely to make L0 look complete."

## Standing

- The research hypothesis recorded at `L8/L0/` (semantic drift expected to originate when the local L0 meaning contract changes or is misapplied) remains open to testing; this sheet does not localize it to any rail.
