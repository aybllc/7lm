# L8/L0/

**Object:** Foundational semantic/rail contract used by the bounded object before admissible state is declared.
**Path:** `L8/L0/` · **Layer:** L0 — LAYER 0 · **Owner:** L8/L0/, as the owner of the bounded object's foundational representation.

Layer 0 is the lowest interior layer of the USO. It holds the foundational distinctions under which this bounded object operates before any admissible state is declared: ontology, semantics, epistemic distinctions, universality, and the pedagogy of how the system is traversed and attached. A distinction may be formulated locally or adopted from an external source. L0 owns the role the distinction plays inside the bounded object; provenance owns the external source relation when that relation matters. Peering is used only when an identifiable external counterpart relationship itself is being represented. The core question is: "What foundational distinctions does THIS bounded object use before an admissible state is declared?"

The specification's analytic view states the reason L0 is a separate layer: "L0 is deliberately separated from L1. L0 establishes the local semantic/foundational contract; L1 establishes admissible states under that contract." Everything in this directory is read under that sentence. A canonical branch below may remain empty; presence in the agnostic topology establishes admissible capability, not mandatory population, and unused now does not mean removed.

### Owns / represents
- Ontological, Semantic, Epistemic, and Universality rail boundaries for this object.
- System-level traversal/attachment pedagogy as a directory/function, without making Pedagogy a fifth rail.
- Vocabulary and semantic representations used by this bounded object, whether locally formulated or explicitly adopted for a stated scope.

### Permitted actions
- place each foundational distinction in the rail that states its role
- state ambiguity or unresolved meaning without filling it by guess
- distinguish semantic use from external provenance when a source relation matters
- record changed meaning as a changed semantic state rather than silently conflating it with the prior state

### Acceptance / boundary check
- Every L1 distinction resolves to an L0 meaning actually used by the bounded object.
- Source origin and semantic role are not conflated: provenance may describe where a meaning came from, while L0 describes what meaning functions here.
- Peering is not required merely because a source is external.
- No neighboring rail silently supplies another rail's local meaning.

## Directory prose and rationale

| Directory / thing | Prose | Why |
|---|---|---|
| L8/L0/ | Layer 0 container for the bounded object's foundational and rail representation. | Keeps foundational meaning distinct from state, formalization, engineering, realized work, research judgment, provenance, and surface exchange. |
| universality/ | Directory for the Universality rail content owned by L0. | Preserves Universality as its own rail instead of letting another rail silently supply it. |
| pedagogy/ | Directory for system-level traversal and attachment pedagogy. | Keeps pedagogy explicit without turning it into a fifth philosophical rail. |
| epistemic/ | Directory for the Epistemic rail content owned by L0. | Keeps epistemic distinctions inside the rail that owns them. |
| ontology/ | Directory for the Ontological rail content owned by L0. | Keeps ontological distinctions inside the rail that owns them. |
| semantics/ | Directory for the Semantic rail content used by this bounded object. | States what meaning functions here while leaving source history to provenance when relevant. |
| semantics/definitions/ | Directory for definitions that function in this bounded object's Semantic rail. | Keeps definition as a semantic role independent from whether the wording was locally authored or externally sourced. |

The four rails — Ontological, Semantic, Epistemic, Universality — each have their own directory. Pedagogy has a directory but is not a rail. `semantics/definitions/` holds definitions that function as definitions for the bounded object; authorship and source are separate provenance questions.

The spec's originating constraint states the Autonomous/Auditonomous relation that this layer must preserve: "Autonomous has one bounded semantic job: state and freeze the narrowest reasonable agreement shared across exact, independently bound standards definitions. It must not manufacture consensus where sources materially disagree; every disagreement remains source-tagged and visible." And: "Auditonomous consumes the pinned Autonomous consensus baseline and authors the Auditonomous difference as an explicit local delta. The baseline and delta remain separately owned and overlaid rather than blended into a dual-owned definition."

**Clarification.** The Autonomous and Auditonomous repositories are implementation work in progress; their current layouts do not control the architecture. Architecture and implementation status are separate claims.

**Exemplar clarification.** A source L0 definition may travel through source L7 egress and receiving L7 ingress when two bounded objects are actually peering. That is one valid route, not the universal route for external meaning. A definition discovered through a book, article, database, archive, standards source, or web search may be adopted at L0 with its provenance represented separately and no peering relation at all.

In the Autonomous/Auditonomous exemplar, the repositories may choose exact version pinning, source tagging, or reference-only handling. Those are exemplar conditions, not the definition of L0 or peering.

## Direction

Construction begins at `L8/L0/` with the foundational distinctions the bounded object actually uses and leaves toward `L8/L1/`. Inspection enters from `L8/L1/` and ends here at the meaning contract under which those states are understood. External source relations may be traced through provenance, and peering may be traced when a peer relationship exists. These are the spec's two valid directions, L0→L1→…→L7 for scientific construction and L7→L6→…→L0 for external inspection; description does not become prescription merely because the structure can be traversed.
