# L8/L0/ontology/

**Object:** Directory for the Ontological rail content owned by L0.
**Path:** `L8/L0/ontology/` · **Layer:** L0 — LAYER 0 · **Owner:** L8/L0/

## What this directory is

Directory for the Ontological rail content owned by L0. The Ontological rail is one of the four rails the L0 sheet names as this object's own boundaries. What is held here is the ontological distinction the bounded object itself establishes, stated before an admissible state is declared. The spec separates the two steps: "L0 establishes the local semantic/foundational contract; L1 establishes admissible states under that contract."

In practice a person filing here records an ontological distinction this object authored, binds it to this rail, states unresolved meaning as unresolved rather than filling it by guess, and versions a changed distinction rather than rewriting prior use. An ontological distinction here is not a state, a coordinate description, or a formal structure; those belong to `L8/L1/` and `L8/L2/`.

## Why it exists

Keeps ontological distinctions inside the rail that owns them. The acceptance check "No neighboring rail silently supplies another rail's local meaning" is satisfied only if the ontological distinctions have a directory of their own.

## Holds

- Ontological-rail distinctions locally authored by this bounded object.
- Statements of ambiguity or unresolved meaning, recorded as unresolved.
- Versioned prior ontological distinctions where a distinction has changed.
- References to any externally owned ontological input, carried as an exact named external semantic binding with object identity, owner, source layer, version, ingress binding, and immutable status.

## Does not hold

- Externally owned definitions or ontologies copied inward — bound through `L7/peering/`, represented at `L7/provenance/`.
- Semantic, epistemic, or universality distinctions — `L8/L0/semantics/`, `L8/L0/epistemic/`, `L8/L0/universality/`.
- Admissible states, possibilities, or exclusions — `L8/L1/state-space/`.
- Exact relations, operators, or proofs — `L8/L2/formal-mathematics/relations/`, `L8/L2/formal-mathematics/operators/`, `L8/L2/formal-mathematics/proofs/`.
- Realized work of any kind — `L8/L4/work/`.

## Boundary / traversal rule

L0/semantics contains the semantic representation authored by the bounded thing. An externally owned definition is not copied into L0 merely to populate the directory. An external ontology is bound and tagged, never re-authored here.

## Standing

- This branch may remain empty. Presence in the agnostic topology establishes admissible capability, not mandatory population; unused now does not mean removed. A rail may remain sparse or gate-only when no local representation has been authored.
- Machine metadata: described at `L8/L0/`; not instantiated in this repository. No automation.
