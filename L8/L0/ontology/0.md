# L8/L0/ontology/

**Object:** Directory for the Ontological rail content owned by L0.
**Path:** `L8/L0/ontology/` · **Layer:** L0 — LAYER 0 · **Owner:** L8/L0/

## What this directory is

Directory for the Ontological rail content owned by L0. The Ontological rail is one of the four rails the L0 sheet names as this object's own boundaries. What is held here is the ontological distinction the bounded object itself establishes, stated before an admissible state is declared. The spec separates the two steps: "L0 establishes the local semantic/foundational contract; L1 establishes admissible states under that contract."

In practice this rail records ontological distinctions that the bounded object actually uses before L1. A distinction may be locally formulated or adopted from an external source. Source origin does not change its L0 rail role; provenance can separately record where it came from. An ontological distinction here is not a state, coordinate description, or formal structure; those belong to `L8/L1/` and `L8/L2/`.

## Why it exists

Keeps ontological distinctions inside the rail that owns them. The acceptance check "No neighboring rail silently supplies another rail's local meaning" is satisfied only if the ontological distinctions have a directory of their own.

## Holds

- Ontological-rail distinctions used by this bounded object.
- Statements of ambiguity or unresolved meaning, recorded as unresolved.
- Versioned prior ontological distinctions where a distinction has changed.
- Source references where useful for orientation; provenance remains separately represented at `L7/provenance/`.

## Does not hold

- External-source provenance as provenance — `L7/provenance/`. Peering applies only when an identifiable external counterpart relationship is itself represented.
- Semantic, epistemic, or universality distinctions — `L8/L0/semantics/`, `L8/L0/epistemic/`, `L8/L0/universality/`.
- Admissible states, possibilities, or exclusions — `L8/L1/state-space/`.
- Exact relations, operators, or proofs — `L8/L2/formal-mathematics/relations/`, `L8/L2/formal-mathematics/operators/`, `L8/L2/formal-mathematics/proofs/`.
- Realized work of any kind — `L8/L4/work/`.

## Boundary / traversal rule

L0 owns the foundational role of this ontological distinction. External origin does not exclude a distinction from this rail when it actually functions here; provenance and peering remain separate external-relation questions.
